# Changelog

## [1.0.0] - 2026-09-30

### Added

- One-click local JSON export through HDT.
- English and Italian installers/export launchers.
- Compact collection format with normal, golden, diamond and signature counts.
- Zero-owned cards omitted.
- Automatic timestamped archive.
- Privacy-conscious public schema without BattleTag/account identifiers.
- Documentation, sample file and troubleshooting guides.
