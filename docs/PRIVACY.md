# Privacy

HDT One-Click Collection Exporter performs the export locally.

The plugin does not require browser automation, HSReplay OAuth access, cookies or web scraping.

## Not included by default

The public export schema omits:

- BattleTag
- Blizzard account hi/lo identifiers
- browser cookies
- HSReplay OAuth tokens

## Data that can still be personal

The JSON can contain:

- your owned-card collection;
- dust count;
- favorite heroes/card backs if HDT exposes them;
- HDT player records.

Review your export before sharing it publicly.

The sample JSON included in this repository is synthetic and contains no real account data.
