# Contributing

Contributions are welcome.

Good contributions include:

- reproducible bug reports;
- compatibility fixes for newer HDT versions;
- installer reliability improvements;
- documentation translations;
- schema improvements;
- tests and validation tools.

## Issues

Please include:

- Windows version;
- HDT version;
- exact error output;
- steps to reproduce.

Please do not include tokens, cookies, credentials or unsanitized personal collection exports.

## Pull requests

Keep changes focused and describe what changed, why it is needed, and how you tested it.

English is preferred for code, comments and primary technical documentation. Additional translations are welcome.
